# FaceUnlock

맥북 내장 카메라로 얼굴을 확인해 화면 잠금을 풀어 주는 메뉴 막대 앱입니다.
개인이 만든 실험용 프로그램이며 Apple의 Face ID와는 관계가 없습니다.

## 설치 전에 꼭 읽어 주세요

- **Face ID만큼 안전하지 않습니다.** 맥북 카메라에는 깊이·적외선 센서가 없고, 얼굴 전용 인식 모델도 쓰지 않습니다. 닮은 사람이나 사진·영상에 잠금이 풀릴 수 있습니다.
- **로그인 비밀번호를 키체인에 저장합니다.** 얼굴이 확인되면 앱이 잠금 화면에 비밀번호를 대신 입력하는 방식입니다.
- **회사에서 관리하는 Mac이나 민감한 자료가 있는 Mac에는 설치하지 마세요.**
- macOS 27.2, Apple Silicon MacBook Pro 한 대에서만 확인했습니다. 다른 버전이나 Intel Mac에서는 동작하지 않을 수 있습니다.
- 잠금 화면에 뜨는 효과는 macOS 내부(비공개) 기능을 써서, macOS 업데이트 후 안 보일 수 있습니다. 그 경우에도 잠금 해제는 그대로 됩니다.

## 필요한 것

- macOS 14 이상, 내장 카메라가 있는 Mac
- 관리자 계정
- Xcode 명령어 도구 (없으면 설치 스크립트가 설치 명령을 알려 줍니다)

## 설치

터미널에서 이 폴더로 이동한 뒤 실행합니다.

```bash
./install.sh
```

앱을 빌드해 `/Applications/FaceUnlock.app`에 설치하고, 로그인할 때 자동으로 실행되게 등록합니다.

## 처음 설정

메뉴 막대의 얼굴 모양 아이콘을 눌러 차례대로 진행합니다.

1. **권한 요청…** — 카메라를 허용하고, 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 FaceUnlock을 켭니다.
2. **얼굴 등록…** — 등록 시작을 누르고 고개를 조금씩 움직입니다.
3. **인식 테스트…** — 본인은 "일치", 다른 사람 얼굴이나 본인 사진은 "불일치"가 나오는지 확인합니다. 다른 얼굴에 "일치"가 나오면 민감도를 "엄격"으로 바꾸세요.
4. **로그인 비밀번호 저장…** — 이 Mac의 로그인 비밀번호를 입력합니다.
5. **얼굴 잠금해제 사용**을 체크합니다.

## 사용

- 화면이 잠긴 상태에서 덮개를 열거나 화면이 켜지면 자동으로 얼굴을 확인합니다.
- 화면이 켜진 채 잠겨 있을 때는 2~3초 뒤 트랙패드를 건드리거나 Shift를 누르면 확인을 시작합니다. (Enter·Space는 피하세요.)
- 카메라 초록불이 켜지고 화면 가운데에 스캔 표시가 나오면 확인 중입니다.
- 안 풀리면 평소처럼 비밀번호나 Touch ID로 풀면 됩니다.

### 일부러 넣어 둔 제한

- 재부팅 후 첫 로그인은 비밀번호가 필요합니다.
- 비밀번호나 Touch ID로 직접 푼 지 12시간이 지나면 얼굴 잠금해제가 작동하지 않습니다.
- 한 번 잠길 때마다 스캔은 최대 3회, 한 번에 8초까지입니다.
- 비밀번호 입력이 2회 실패하면 직접 풀 때까지 멈춥니다.

## 문제가 생겼을 때

- 메뉴의 **로그 보기**에 스캔 과정과 건너뛴 이유가 남습니다.
- **"건너뜀: 손쉬운 사용 권한 없음"** — 다시 설치했거나 권한이 꼬인 경우입니다. 아래 명령을 실행한 뒤 메뉴의 "권한 요청…"부터 다시 하세요.

  ```bash
  tccutil reset Accessibility local.faceunlock.app
  ```

- **다시 설치한 뒤에는** 권한 허용과 "로그인 비밀번호 저장"을 다시 해야 합니다. 등록한 얼굴은 유지됩니다.
- **본인인데 자주 안 풀리면** "얼굴 샘플 추가…"로 다른 조명이나 안경 쓴 모습을 더 등록하세요.

## 삭제

```bash
./uninstall.sh
```

앱, 자동 실행 항목, 등록된 얼굴 데이터, 키체인에 저장된 비밀번호 사본, 설정과 로그를 모두 지웁니다.

## 저장되는 것

| 무엇 | 어디 |
|---|---|
| 얼굴 특징값 (사진이 아닌 숫자 목록) | `~/Library/Application Support/FaceUnlock/profile.json` |
| 로그인 비밀번호 사본 | 키체인의 "FaceUnlock 로그인 비밀번호" 항목 |
| 로그 (비밀번호는 기록하지 않음) | `~/Library/Logs/FaceUnlock.log` |

카메라 영상은 저장하지 않고, 어떤 정보도 Mac 밖으로 보내지 않습니다.
